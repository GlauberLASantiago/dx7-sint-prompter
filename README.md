# DX7 FM Synth & AI Prompt Builder

Aplicação web progressiva (PWA) para experimentar presets de síntese FM inspirados no Yamaha DX7, tocar um acorde em Web Audio API e gerar prompts para IA a partir dos parâmetros escolhidos.

## Créditos

Projeto com créditos para **Prof. Glauber Santiago - UFSCar**.

## Funcionalidades

- Seleção rápida de presets inspirados em timbres clássicos.
- Controle de razão do carrier, razão do modulator, índice de modulação e volume.
- Reprodução de acorde em síntese FM via Web Audio API.
- Geração de prompt para IA com base na configuração atual.
- Instalação como PWA com cache offline dos arquivos estáticos.

## Descrição

O projeto oferece uma interface simples, em português, para estudar síntese FM de 2 operadores e transformar os parâmetros sonoros em instruções reutilizáveis para modelos de IA e experimentos com áudio no navegador.

## Tags

`pwa`, `dx7`, `fm-synthesis`, `web-audio-api`, `javascript`, `ufscar`

## Como usar

1. Abra o arquivo `index.html` em um servidor estático.
2. Escolha um preset ou ajuste os controles manualmente.
3. Use **Tocar Cmaj7 DX7** para ouvir o timbre.
4. Use **Gerar Prompt para IA** para montar o texto com a configuração atual.
5. Instale o app pelo botão **Instalar aplicativo** quando o navegador oferecer suporte.
